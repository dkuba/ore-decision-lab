# Технический отчёт по первой реализации PoT

**База:** литературно обоснованный синтетический пакет, зафиксированный до веб-реализации. **Проверено:** 23 ноября 2026 года в изолированной среде исполнения.

## Расчётное ядро

- Оригинальный Python: **39/39** unit-тестов пройдены на исходном пакете.
- Новый TypeScript: **22/22** тестов, включая сопоставление с **14 опубликованными контрольными векторами Python** и отрицательные сценарии: нет тестов, нет минералогии, непригодная площадка, выбракованный лабораторный повтор, утраченная средняя точка, выход за диапазон, конкурирующая модель потерь, изменение стоимости/продуктов меняет SHA-256.
- В частях Python- и TypeScript-логики возможны намеренно более консервативные различия: при утрате критичного среднего узла C новый TypeScript не объявляет единственную оставшуюся схему победителем. При обычных исходных данных контрольно-расчётные результаты совпадают с опубликованными векторами.

## UI и статическая сборка

- Chromium (offline, локальное in-memory внедрение тех же JSON-файлов; сеть и навигация заблокированы политикой среды): нет JavaScript `pageerror`.
- Проверена смена руды, grade 1,40, переключение `constant_residue`, открытие `SYN-P07`, ввод 1,85 → `out_of_scope`, переключение языка.
- Проверен viewport 1600 × 960 и 390 × 844; **ширина документа не больше viewport**. Это базовая проверка адаптивности, не полноценная кроссбраузерная квалификация.
- Проверить на реальном `https://` окружении перед публикацией: `navigator.clipboard`, `crypto.subtle`, `mailto`, настоящие URL, внешние ссылки на литературу; offline тесты исполнялись на `about:blank`, поэтому они не проверяют защищённый контекст браузера.

## Не доказано

- Промышленная представительность проб, значения извлечений и экономические коэффициенты; это полностью искусственные данные.
- Пригодность площадки для кучного выщелачивания (не проведён загруженный Ksat).
- Равная квалификация моделей потерь; постоянные хвосты противоречат крайним синтетическим точкам.
- Заказное техническое заключение независимого обогатителя и промышленное проектирование.
- Публикация сайта в GitHub Pages: доступ к удалённому репозиторию через GitHub connector в этой сессии отсутствует (404); подготовлен проект и CI workflow, **не выполнена операция push**.
